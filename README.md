# ChromaPicker

**Chromapick — Free Image Color Picker & Palette Studio**

A fast, client-side, mobile-first responsive image color extractor, palette generator, and color science suite built with React and Vite.

## Features
- **Instant Color Extraction**: Extract dominant colors, palettes, and frequencies from uploaded, pasted, or URL images.
- **Pixel-Accurate Magnifier Loupe**: Precision inspection with live HEX/RGB crosshairs, adjustable zoom, and mobile touch-and-drag support.
- **Harmonies & Conversions**: Convert HEX, RGB, HSL, CMYK, LAB, and explore complementary, triadic, and analogous palettes.
- **Accessibility & Contrast**: Built-in WCAG 2.1 AA/AAA contrast checker and CVD blindness simulation (Protanopia, Deuteranopia, Tritanopia, Monochromacy).
- **Multiple Export Formats**: CSS variables (:root), SCSS, JSON, Adobe Swatch Exchange (ASE), SVG, PNG palette cards, and GIMP/Inkscape GPL.
- **100% Client-Side Privacy**: All image processing and color calculations run directly in the browser with zero external server uploads.
- **Fully Responsive**: Mobile-first design for 320px–480px phones, tablets, and 3-column desktop layout with ad gutters.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run test suite
npm test

# Build for production
npm run build
```
